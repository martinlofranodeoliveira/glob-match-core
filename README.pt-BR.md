# glob-match-core

Compilador de glob para RegExp com casamento: estrela, interrogação,
dupla-estrela, classes. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 4 testes, node:test, sem dependências
npm run demo
```

Pontos são caracteres comuns. MIT — veja `LICENSE`.
